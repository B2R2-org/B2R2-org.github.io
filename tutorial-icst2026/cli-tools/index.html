Basic CLI Tools

The B2R2 launcher provides small command-line tools for inspecting, disassembling, assembling, and exploring binaries. The examples below all run from the extracted demo directory.

Demo Target

Section titled “Demo Target”

Download demo files

The demo archive contains:

  • examples/echo: a stripped x86-64 ELF binary
  • examples/asm.s: an assembler example

After extracting the archive, run commands from the demo directory so the examples/... paths match the commands below.

b2r2 scan

Section titled “b2r2 scan”

scan reads binary metadata without executing the target.

Use this to inspect:

  • file format, architecture, and entry point
  • stripped status, NX, and PIE
  • section layout
  • symbols and PLT entries

b2r2 disasm

Section titled “b2r2 disasm”

disasm prints a section-level disassembly and can also lift instructions to LowUIR.

Use this to inspect:

  • section-level disassembly
  • PLT stubs as imported-call entry points
  • LowUIR output from --lift

b2r2 explore

Section titled “b2r2 explore”

explore recovers functions and opens the Avalonia GUI by default.

Use --no-gui when you want terminal-only output or when a GUI environment is not available.

Use this to inspect:

  • function list
  • section list
  • disassembly and CFG workspace
  • hex overview and hex view
  • navigation toolbar and status bar
